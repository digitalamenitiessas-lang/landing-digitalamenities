# Digital Amenities Landing

Landing institucional en `Next.js` para Digital Amenities.

## Requisitos

- Node.js
- npm

## Desarrollo

```bash
npm install
npm run dev
```

## Estructura

- `src/app/page.tsx`: home principal
- `src/data/site-content.ts`: textos, links y casos
- `src/app/fonts`: tipografia `Karla` tomada del manual de marca
- `public/assets`: logos de marca, productos y clientes
